# AE 采集 + 多通道定位 GUI v5

本版本在 v4 界面基础上保持 UDP 收发和采集流程不变，新增/修改：

1. 采样通道仍通过 UDP 参数页的 `通道掩码` 设置，例如 `000F`、`00FF`、`FFFF`。
2. 数据保存页新增 CH1~CH16 的传感器名称设置。
3. 手动保存时根据 FPGA 回传事件头中的 `channel_mask` 自动保存有效通道数据。
   文件名规则为：`Nchannel_x_y.csv`，其中 `N` 为实际保存的有效通道数，`x/y` 为实际目标坐标。
4. CSV 列名包含通道号和传感器名称，例如 `CH01_S1`。
   同时保存同名 JSON，包含有效通道、传感器名称、目标坐标、传感器坐标、事件序号和采样率等元信息。
5. 定位参数默认：WPT 层数 `4`，能量阈值 `0.001`。
6. 定位参数页新增 `定位通道数` 下拉框，可选 `4 / 8 / 12 / 16`。
7. 定位时使用当前事件回传 channel_mask 中排序靠前的 N 个有效通道，且 N 不能大于当前有效采样通道数。
8. 传感器坐标扩展为 CH1~CH16，可按实际布置修改。
9. AE 波形页仍显示 CH1~CH16；定位结果页显示定位图、参考通道时域信号、子波包能量图/表和子带定位结果表。

运行：

```bash
python ae_gui.py
```

依赖见 `requirements.txt`。


## v6 更新说明

- CH1~CH16 定位传感器坐标初始值均为 `(0, 0)`。
- 传感器坐标设置移动到“数据保存”页；保存 CSV 时会在同名 JSON 中保存传感器名称、传感器坐标、目标实际坐标、有效通道等元数据。
- 新增“加载已保存数据用于定位”按钮。定位参数页可在“当前采集数据”和“已加载保存数据”之间选择定位数据来源。
- 定位图中的传感器实际位置改为灰色圆形，按实际直径 12 mm 显示。
